# Authentication System

## Overview

This project is a modern Authentication System developed using HTML, CSS, JavaScript, and Node.js.

It includes a professional login page and an interactive admin dashboard with modern UI features.

---

# Features

- User Login System
- Admin Dashboard
- Dark Mode Toggle
- Live Date and Time
- Sidebar Navigation
- Notifications Section
- Analytics Cards
- Progress Bars
- Activity Chart
- Responsive Design
- Glassmorphism UI
- Logout Functionality

---

# Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

---

# How to Run

1. Open the project folder in VS Code.
2. Open terminal.
3. Install dependencies:

```bash
npm install
```

4. Start the server:

```bash
node server.js
```

5. Open browser and visit:

```text
http://localhost:3000
```

---

# Project Structure

- index.html → Login Page
- dashboard.html → Admin Dashboard
- style.css → Styling
- script.js → JavaScript Logic
- server.js → Backend Server
